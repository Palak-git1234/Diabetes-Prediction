# Diabetes Prediction using Machine Learning

## Overview
This project predicts whether a patient is diabetic using machine learning classification algorithms.

## Dataset
- Pima Indians Diabetes Dataset
- 768 patient records
- 8 medical features
- Target: Outcome (0 = Non-Diabetic, 1 = Diabetic)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Features
- Data preprocessing
- Missing value handling
- Feature scaling
- Model training
- Performance evaluation
- Confusion Matrix
- Classification Report

## Results
The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
